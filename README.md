# 潮涌双城记

一本以广东与江苏的发展为线索的经济学小说。本仓库保存独立章节，为后续小说网站提供内容来源。

[打开小说目录](潮涌双城记-目录.md)

## 内容结构

- `小说/`：序章与 54 个正式章节，每章一个 Markdown 文件。
- `创作资料/`：第十五章的改写版本，供写作比较使用。
- `潮涌双城记-目录.md`：章节链接与原稿待补记录。

章节文件使用三位数字前缀排序，例如 `001-第一章：苏南模式——县域经济的突围.md`。现有编号保留原稿中的空缺。

## 供网站读取的章节属性

每篇文件顶部包含 YAML 属性：

| 属性 | 含义 |
| --- | --- |
| `title` | 完整章节标题 |
| `book` | 所属小说名 |
| `chapter` | 数字章号，序章为 0 |
| `slug` | 稳定的网址标识，例如 `chapter-001` |
| `type` | 正式章节为 `chapter`，改写资料为 `revision` |

网站可以读取 `小说/` 下的 Markdown，筛选 `type: chapter`，按 `chapter` 数值排序，并将 `slug` 用作页面路径。`创作资料/` 不纳入正式阅读目录。修改章节标题时保留原有 `slug`，可保持网址稳定。

正文保留原稿内容和格式，包括经济学知识点与已有修改说明。本仓库尚未包含网站程序或部署配置。
