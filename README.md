# 潮涌双城记

一本以广东与江苏的发展为线索的经济学小说。本仓库保存独立章节，为后续小说网站提供内容来源。

[在线阅读](https://siliconaiedu.github.io/Ethan-Novels/) · [Markdown 目录](潮涌双城记-目录.md)

## 内容结构

- `小说/`：序章与 75 个正式章节，每章一个 Markdown 文件。
- `创作资料/`：第十五章的改写版本，供写作比较使用。
- `潮涌双城记-目录.md`：章节链接和小说的虚构时间线说明。

章节文件使用三位数字前缀排序，例如 `001-第一章：苏南模式——县域经济的突围.md`。章节编号从序章连续到第七十五章。

## 供网站读取的章节属性

每篇文件顶部包含 YAML 属性：

| 属性 | 含义 |
| --- | --- |
| `title` | 完整章节标题 |
| `book` | 所属小说名 |
| `chapter` | 数字章号，序章为 0 |
| `slug` | 稳定的网址标识，例如 `chapter-001` |
| `type` | 正式章节为 `chapter`，改写资料为 `revision` |

网站可以读取 `小说/` 下的 Markdown，筛选 `type: chapter`，按 `chapter` 数值排序，并将 `slug` 用作页面路径。`创作资料/` 不纳入正式阅读目录。修改章节标题时保留原有 `slug`，可保持网址稳定。

正文保留原稿内容和格式，包括经济学知识点与已有修改说明。网站已包含电脑与手机自适应布局、章节搜索、上一章/下一章、字号调整和本机阅读进度记忆。

## HTML 网站与自动发布

- 公开网址：https://siliconaiedu.github.io/Ethan-Novels/
- `index.html`：可直接在浏览器打开的完整阅读页面，章节、样式和交互均已内嵌；背景图片位于 `assets/reading-garden.jpg`，移动文件时请一同保留。
- `web/`：页面模板、样式与交互源文件。
- `scripts/build_site.py`：从「小说」中的 Markdown 生成 HTML，不需要安装第三方依赖。
- `.github/workflows/pages.yml`：每次推送到 `main` 后重新生成页面并发布到 GitHub Pages。

本地预览：执行 `python3 scripts/build_site.py`，再执行 `python3 -m http.server 8765 --directory _site`，打开 `http://localhost:8765/`。

继续在「小说」中新增或修改章节并上传到 GitHub，网站会自动更新。若需要更新本地 `index.html`，重新执行生成命令。阅读器按章节顺序翻页。改写资料不进入网站阅读目录。

背景为本次创作的绿植绒面图像，网页使用压缩后的 JPEG；阅读版展示章节稿，去除原稿中大面积的粗体标记以便长篇阅读。网站不使用外部字体、广告或统计追踪服务；阅读进度和字号仅保存在读者自己的浏览器中。
