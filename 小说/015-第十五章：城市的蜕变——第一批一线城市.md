# 第十五章：城市的蜕变——第一批一线城市

  
**二〇二六年冬，深圳前海，一场别开生面的“城市进化论”论坛正在举行。**  
  
**受城市功能评估组邀请，曾在英国研究城市网络的许文礼教授从伦敦回到深圳。他在一处城中村长大，到会场前特地绕到当年读书的地方看了一眼。**  
  
**大屏幕上是一张珠三角的网络图。不同颜色的线标出通勤、就医和企业服务。台下有人等宣布名次，还有人想看本地哪一条线画得短了。**  
  
**“经第一轮核验，广州、深圳、佛山、东莞进入省里的一线功能城市名单。”许教授指给人看，“这份评估有公共服务、专业分工和运营可持续性几条线。国际机构有各自的排行，我们这张表用来看三年后在册的服务还能否照常开门。”**  
  
**台下响起热烈的掌声。**  
  
**许教授推了推眼镜，又翻出两页。佛山有不少厂已能替外地小企业独立做模具和材料检验，东莞的车间有成套的试制服务。各自还有办得不好的地方。许指着图上两条浅线，请两地留下低收入居民通勤的原始记录，复评时要去走一次。**  
  
**林怀南坐在台下，想起上世纪九十年代第一次来东莞调研的情景。街道尘土飞扬，工厂宿舍挨在一处。他那时只在笔记里记下每小时做出多少件，忘了问工人下了班有几路车可以乘。**  
  
**过了三十多年，才想起补问也不算太晚。他在纸上写下当日的一路公交和两处给外地企业办检验的地方。**  
  
**论坛结束后，许教授找到林怀南，两人在会场外的咖啡厅坐下。**  
  
**“林教授，”许教授搅动着咖啡，“佛山和东莞的企业能接的活多了。这两张表，哪一张该先看？”**  
  
**林怀南想了想，从包里掏出两张图表。**  
  
**“许教授，我在东莞跟踪了十八家工厂。看看这一张。过去检验归在工厂里，同一台设备只给一家用。近年有几家把检测另立成公司，同行的活也接了。账面上服务业多了一笔，能做检验的人和时段也确实比从前多一些。”**  
  
**他指着图表中的一行。研发设计、检测认证、供应链管理、物流和金融都可以供制造业使用。不过把原来的人换一个发工资的单位，城里未必会多出一分产出。可若一个质检员能给几家小厂服务，并且把从外地拿回来的难单子做成，增加的本事便有了用处。**  
  
**许教授点点头，问他们有没有那几组检验数据，又在哪儿能坐到去工厂的车。**  
  
**“正是如此。”林怀南点头，“这就是杨格定理在区域经济中的体现**——**分工受市场范围限制，市场的扩大又会进一步促进分工。东莞的市场范围从全国扩展到全球，分工的精细化程度也随之指数级增长。原先一个工厂内部完成的几十个环节，现在变成了几十家专业公司，每一家都在自己的细分领域做到了世界级水平。”**  
  
**许教授从口袋里取出一支钢笔，在纸巾上记了两个地址。他原来约好第二天去看新的展厅，添了这两个地址，恐怕要早起一个钟头。**  
  
**林怀南问他几时出门。许望了一眼会场外闪亮的路灯，说先搭第一班车，若不能到，就看看还差哪一段。**
